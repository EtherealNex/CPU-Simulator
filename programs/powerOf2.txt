// To use, change the number at INPUT1 to be the value you want.

INPUT LDA INPUT1
        STA NUM
        STA COUNTER

CHECK LDA COUNTER
        BRZ OUTCODE

LOOP LDA RESULT
ADD NUM
STA RESULT

SUBBER LDA COUNTER
SUB CONST1
STA COUNTER
BRA CHECK

OUTCODE LDA RESULT
OUT
HLT

CONST1 DAT 1
NUM DAT
COUNTER DAT
RESULT DAT
INPUT1 DAT 5
